# Vườn Từ Vựng – cải thiện phát âm

Bản này giữ nguyên dữ liệu, giao diện và chức năng học từ vựng; chỉ cập nhật lựa chọn giọng đọc tiếng Anh và thiết lập phát âm.

- Ưu tiên giọng English (United States) chất lượng cao nếu trình duyệt/hệ điều hành có sẵn (Google US English hoặc giọng Microsoft Natural/Online tương thích).
- Tốc độ đọc 0.82, cao độ 1.02, âm lượng tối đa.
- Nếu thiết bị không có giọng ưu tiên, tự động dùng giọng en-US tốt nhất hiện có.

Lưu ý: giọng thực tế phụ thuộc các voice được cài/được trình duyệt cung cấp trên thiết bị. Microsoft Edge thường có thêm giọng trực tuyến tự nhiên; hãy thử mở bằng Edge nếu Chrome vẫn đọc bằng giọng máy cũ.
